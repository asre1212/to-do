# To Do

A simple, minimalist, local-first to-do PWA with four tabs:

- This week
- This month
- General
- Aspirational

Tasks are saved on the device in browser storage. Checking a task marks it complete and removes it from the list. Each category has its own notes area, also saved locally.

Use **Export** to download a JSON backup and **Import** to restore it later. Browser/PWA storage can be cleared by deleting browser data, so the exported backup file is the durable copy to keep when changing phones.

On iPhone, open the site in Safari and choose **Share > Add to Home Screen** to install it as a PWA.

## Run

Open `index.html` in a browser, or serve the folder with any static file server.
